# Бот «Аналитик прайсов» 🍺

Telegram-бот для пивного бара: принимает прайсы поставщиков **в любом виде** —
Excel, PDF, ссылку на Google-таблицу или сайт — разбирает их, приводит все цены
к единому виду и отвечает на вопросы: где самый дешёвый хеллес, у кого выгоднее
IPA, что подорожало с прошлой недели.

Проект создан владельцем бара с нулевым опытом в программировании
в паре с ИИ-агентом Claude Code.

## Что умеет

- **Принимает прайсы любым способом:**
  - файлом Excel (`.xlsx`, `.xls`) или PDF прямо в чат;
  - ссылкой на Google-таблицу;
  - ссылкой на сайт-прайс (по «профилю» сайта);
  - сам определяет поставщика по имени файла, а если не уверен — спрашивает в чате.
- **Приводит цены к единому виду** — главная формула проекта:
  кеги и пэты считаются **за литр**, банки и бутылки — **за штуку**.
  Если поставщик написал цену за весь кег или коробку — бот пересчитает сам.
- **Отвечает на вопросы обычными словами**, по-русски: «найти IPA до 300»,
  «сравнить хеллес», «что подорожало», «отчёт по стауту».
- **Знает, что является пивом:** лимонады, квас и вода не попадают в топы
  «самое дешёвое» и не искажают сравнение.
- **Помнит историю цен** по датам — и показывает динамику подорожаний.
- **Экспортирует полные отчёты в Excel** — двумя листами:
  «Кеги и пэты (за литр)» и «Банки и бутылки (за штуку)».
- **Доступ только по списку допуска** (Telegram ID): посторонние получают вежливый отказ.

## Команды

| Команда | Или по-русски | Что делает |
|---|---|---|
| `/start` | — | шпаргалка: что умеет бот |
| `/digest` | «дайджест» | сводка по последнему присланному прайсу |
| `/find IPA до 300` | «найти IPA до 300» | поиск у всех поставщиков, «до 300» — потолок цены |
| `/find пивоварня jaws` | «найти пивоварня jaws» | всё от одной пивоварни |
| `/compare хеллес` | «сравнить хеллес» | у какого поставщика дешевле |
| `/changes` | «изменения» | что подорожало/подешевело между прайсами |
| `/report хеллес` | «отчёт хеллес» | все найденные позиции — файлом Excel |
| `/sort` | «сортировка» | всё пиво по возрастанию цены |

## Как это устроено

```
bot.py           — «мозг»: приём сообщений и файлов в Telegram, команды
config.py        — настройки: список допуска, справочники поставщиков
price_parser.py  — читатель прайсов: Excel/PDF → позиции, объёмы, цены
price_report.py  — аналитика: поиск, сравнение, динамика цен
price_export.py  — сборка полных отчётов в Excel
site_fetch.py    — чтение сайтов-прайсов по «профилям»
google_fetch.py  — чтение Google-таблиц по ссылке
профили/         — правила чтения конкретных сайтов (один файл — один сайт)
```

Данные хранятся в простых форматах (CSV-история, Excel-отчёты), без баз данных.

## Как запустить у себя

1. Создайте бота у [@BotFather](https://t.me/BotFather) в Telegram и получите токен.
2. Установите Python 3.10+ и зависимости:

   ```
   pip install python-telegram-bot openpyxl pdfplumber httpx
   ```

3. В папке проекта создайте файл `.env` с одной строкой (токен из BotFather):

   ```
   BOT_TOKEN=ваш_токен
   ```

4. В `config.py` впишите в список `ALLOWED_IDS` свой Telegram ID
   (узнать: любой бот «узнать мой ID»).
5. Запустите:

   ```
   python bot.py
   ```

Бот можно запустить на любом компьютере или VPS и держать включённым
круглосуточно — например, через systemd (Linux) или Планировщик задач (Windows).
