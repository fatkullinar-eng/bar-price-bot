# Деплой на сервер (перенос изменений в облако)

Открой этот справочник для запросов «выложи на сервер», «задеплой»,
«перезапусти бота после правок».

В примерах: `<пользователь>@<адрес-сервера>` — ваш ssh (подставьте
свои значения от хостера), путь проекта на сервере —
`/opt/bar-price-bot` (подставьте свой, если другой). Служба —
`bar-price-bot`.

## Золотое правило

На некоторых VPS классическая передача файлов (scp / sftp)
**зависает**. Надёжный способ — «труба» через ssh: файл упаковывается,
едут по ssh и распаковываются на месте. Работает всегда.

## Передача файлов

Команды запускать из папки проекта.

**Несколько файлов** — перечислять файлы явно, НЕ папку:

```
tar czf - bot.py config.py | ssh <пользователь>@<адрес-сервера> "tar xzf - -C /opt/bar-price-bot"
```

ВНИМАНИЕ-ловушка: если аргументом tar указать ПАПКУ и распаковать
с `-C` в ту же папку — получится матрёшка `папка/папка`, и файлы
лягут не туда. Поэтому только список файлов через пробел.

**Один файл:**

```
ssh <пользователь>@<адрес-сервера> "cat > /opt/bar-price-bot/bot.py" < bot.py
```

## Стандартный цикл деплоя (шаги по порядку)

1. **Локально:** правка внесена, тест в песочнице (копия `история/`)
   прошёл, владелец подтвердил. Составить список изменённых файлов.
2. **Резервные копии на сервере** (каждый изменяемый файл):

   ```
   ssh <пользователь>@<адрес-сервера> "cp /opt/bar-price-bot/bot.py /opt/bar-price-bot/bot.py.bak"
   ```

3. **Передать изменённые файлы** (командами выше).
4. **Перезапустить:** `ssh ... "systemctl restart bar-price-bot"`.
5. **Проверить статус:** `ssh ... "systemctl status bar-price-bot --no-pager"` —
   должно быть active.
6. **Проверить старт:** `ssh ... "tail -n 20 /opt/bar-price-bot/bot-log.txt"` —
   без Traceback.
7. **Отчитаться владельцу:** список переданных файлов, что изменилось,
   результат — простыми словами. Попросить проверить живьём
   (например, отправить боту `/start` или тестовую команду).

## Откат, если после деплоя стало хуже

1. Восстановить из резервной копии:
   `ssh ... "cp /opt/bar-price-bot/bot.py.bak /opt/bar-price-bot/bot.py"`.
2. `ssh ... "systemctl restart bar-price-bot"` и проверить статус
   и дневник.
3. Резервные копии (.bak) на сервере НЕ удалять без разрешения.

## Чего НЕ делать

- НЕ деплоить, если не было подтверждения владельца на правку.
- НЕ git на сервере — деплой только файлами.
- НЕ устанавливать пакеты на сервер без подтверждения владельца.
- НЕ трогать `bot-log.txt` кроме чтения.
- НЕ перезапускать «на всякий случай» без причины — сначала
  диагностика (`диагностика-и-перезапуск.md`).
- НЕ запускать двух ботов одновременно (сервер + локально) —
  конфликт 409 в Telegram.
