# Карта проекта бота

Открой этот справочник, когда нужно понять, что где лежит в боте,
спланировать правку или обновить README.

## Файлы: что делает каждый и что в нём менять

- **`bot.py`** — «мозг» бота: приём сообщений и файлов в Telegram,
  список допуска, команды, отправка ответов. Правки поведения бота
  и новые команды — здесь.
- **`config.py`** — настройки (создаётся из образца `config_example.py`):
  `BOT_NAME` (имя бота), `ALLOWED_IDS` (список допуска — добавить
  человека = вписать его Telegram ID сюда), `SUPPLIER_ALIASES`
  (справочник «слово из имени файла → чистое имя поставщика»),
  `PET_PER_LITER_SUPPLIERS` (поставщики, у которых цена ПЭТ указана
  за литр, а не за всю тару).
- **`price_parser.py`** — «читатель» прайсов: открывает Excel (openpyxl)
  и PDF (pdfplumber), вытаскивает пивоварню / название / стиль / тару /
  объём / цену, приводит к правилу бара (кеги и пэты — за литр, банки
  и бутылки — за штуку), пишет CSV в `история/`. Правки разбора
  прайсов — здесь. Тестировать ТОЛЬКО на копиях в песочнице.
- **`price_report.py`** — аналитика по истории: digest / find /
  compare / changes (команды `/digest`, `/find`, `/compare`,
  `/changes` и те же слова по-русски). Только читает `история/`
  и возвращает текст — сама в Telegram не пишет.
- **`price_export.py`** — упаковщик отчётов в Excel для `/report`
  и `/sort`. Копия каждого отчёта — в `отчёты/`.
- **`site_fetch.py`** — чтение сайтов-прайсов: грузит профили
  поставщиков из `профили/`, скачивает страницы (httpx), отдаёт
  в общий конвейер парсера. Незнакомый домен = вежливый отказ
  (UnknownSiteError).
- **`профили/<домен>.py`** — «ключ» к конкретному сайту: DOMAIN,
  SUPPLIER, PAGES, parse_page. Новый сайт-поставщик = новый профиль
  здесь.
- **`google_fetch.py`** — чтение Google-таблиц по ссылке: просит
  у Google копию в формате Excel, сохраняет в `прайсы/`, дальше
  работает обычный Excel-читатель.
- **`README.md`** — публичное описание проекта для людей: что умеет,
  команды, как запустить у себя.

## Папки

- **`прайсы/`** — оригиналы присланных прайсов (Excel, PDF, HTML).
  Не изменять и не удалять.
- **`история/`** — CSV-история
  «ГГГГ-ММ-ДД — Поставщик — данные.csv». Только чтение; тесты —
  на копиях в песочнице.
- **`отчёты/`** — готовые Excel-отчёты бота (результат `/report`
  и `/sort`).
- **`профили/`** — профили сайтов-прайсов.
- **`.env`** — секретный файл с токеном бота (создаётся владельцем,
  в репозиторий не входит). Не читать, не показывать.

## Рецепты типовых задач

### Добавить человека в бота (бармен, партнёр)

1. Узнать у владельца Telegram ID нового человека (проще всего:
   человек пишет боту любое сообщение — бот в отказе покажет свой ID).
2. Добавить ID в `ALLOWED_IDS` в `config.py` (по правилам: сначала
   план владельцу, потом правка).
3. Задеплоить `config.py` на сервер (см. `деплой-на-сервер.md`)
   и перезапустить бота.
4. Обновить README, если порядок изменился.

### Новый поставщик

1. Если имя поставщика в имени файла угадается плохо — добавить
   псевдоним в `SUPPLIER_ALIASES` в `config.py`.
2. Если прайс разбирается неверно — править `price_parser.py`
   (всегда с тестами на копии истории в песочнице; разведку структуры
   удобно делать отдельным скриптом-«фонариком», который печатает
   заголовки и первые строки таблицы).
3. Если у поставщика цена ПЭТ за литр — добавить его
   в `PET_PER_LITER_SUPPLIERS` в `config.py`.
4. Задеплоить изменённые файлы.

### Новая команда

1. Хендлер — в `bot.py`. **Имя команды со слэшем — ТОЛЬКО латиница,
   цифры и подчёркивание** (русские буквы в названии команды =
   ValueError при старте, бот не запустится). Русское слово как
   обычное сообщение — можно.
2. Если команда аналитическая — логика в `price_report.py`
   или `price_export.py` (они ничего не отправляют в Telegram,
   отправляет только bot.py).
3. Обновить таблицу команд в README.
4. Прогнать тесты в песочнице, задеплоить, перезапустить, попросить
   владельца проверить живьём.

3. «Как это устроено» — сверить с фактическим списком файлов и папок.
4. «Как запустить у себя» — проверить, что шаги реально работают
