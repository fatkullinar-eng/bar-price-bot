# Скилл «бот-аналитик-прайсов»

Проект — Telegram-бот для пивного бара: принимает прайсы поставщиков
в любом виде (Excel, PDF, Google-таблица, сайт), приводит цены к единому
виду (кеги и пэты — за литр, банки и бутылки — за штуку) и отвечает
на вопросы: где дешевле, что подорожало, полный отчёт файлом.

Скилл написан для владельца-новичка: **объясняй простыми словами,
каждый шаг — до выполнения**.

## Когда вызывать

- «бот молчит», «бот не отвечает», «проверь бота»;
- «перезапусти бота», «выложи изменения на сервер», «задеплой»;
- «измени бота», «добавь поставщика», «добавь команду», «добавь человека в бота»;
- «обнови README», «как устроен бот»;
- «опубликуй проект», «выложи на GitHub».

**Граница:** скилл действует внутри папки проекта бота. Запросы
о посторонних файлах — не к этому скиллу.

## Как устроена работа (знать всегда)

- **Основной режим — сервер.** Бот работает круглосуточно на VPS
  (Ubuntu Linux) под управлением службы systemd с именем `bar-price-bot`
  (автозапуск при включении сервера, Restart=always). Код и данные —
  в папке проекта на сервере.
- **Запасной режим — локальный запуск** (`python bot.py` на любом
  компьютере).
- **Строго:** два запущенных бота одновременно = конфликт 409 в Telegram
  (сообщения перестают приходить). Перед локальным запуском — остановить
  серверного, и наоборот.

## Правила безопасности (строго, без исключений)

1. **Перед ЛЮБЫМ изменением файлов — покажи план и получи подтверждение.**
   Не удаляй и не переименовывай файлы без отдельного разрешения.
2. **Файл `.env` никогда не открывай и не показывай.** Живость токена
   проверяй только командой `Select-String -Pattern '^BOT_TOKEN=.+' .env`
   (запускать из папки проекта) — ответ «есть строка / нет строки»,
   содержимое не выводится.
3. **Не выходи за пределы** папки проекта.
4. **Ничего не отправляй во внешние сервисы**, кроме Telegram API
   (работа самого бота) и сервера владельца по ssh. Публикация на GitHub
   (создание репозитория, push) — ТОЛЬКО после явного разрешения,
   отдельным шагом.
5. **Тесты парсера — только на копиях** истории в песочнице
   (например, `tmp/история-песочница`), никогда на реальной `история/`.
6. **На сервере ничего не устанавливай** и не запускай команды сверх
   описанных в справочниках — без подтверждения.
